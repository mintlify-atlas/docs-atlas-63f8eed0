Anatomy is an agent skill that turns technical concepts into crafted, interactive isometric figures. Ask your AI coding agent to explain a token bucket, a CDN cache, or a database connection pool — Anatomy invents the right physical machine, builds it from dozens of precise parts, adds live readouts and calm motion, and delivers standalone HTML, SVG files, or React components that you own.

## What Anatomy makes

Every figure is a real, well-made physical object whose working mechanism *is* the concept being explained. A cache key becomes a pin-tumbler lock. A connection pool becomes a gantry plotter. Figures ship as standalone HTML pages, lone SVG files, or React/Next.js components.

## Get started

<Steps>
  <Step title="Install the skill">
    Add Anatomy to your agent with the skills CLI — globally for you, or just for the current project.

    ```bash
    npx skills add wheresryan22/anatomy -g -a claude-code
    ```
  </Step>
  <Step title="Ask for a figure">
    In Claude Code, use the `/anatomy` slash command and describe what you want to explain:

    ```text
    /anatomy explain how a token bucket rate limiter works, interactive
    ```
  </Step>
  <Step title="Receive your figure">
    Anatomy delivers a Node build script and the standalone HTML page it writes, or React geometry modules and components if you asked for React. Open the `.html` file in a browser to see it immediately.
  </Step>
  <Step title="Verify and iterate">
    Run the build with `--audit` to prove geometry correctness, use the capture scripts for close-up screenshots, and iterate on the design.

    ```bash
    node examples/dial-indicator/build.mjs --audit
    ```
  </Step>
</Steps>
